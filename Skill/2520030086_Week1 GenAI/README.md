# Week 1 - First LLM API Call

## Objective
Connect a Python program to an LLM using the Gemini API.

## Files
- main.py - Python program to call Gemini API
- .env - Stores API key locally
- .gitignore - Excludes secret and environment files
- requirements.txt - Required Python packages
- .venv - Python virtual environment

## Run the project
1. Activate virtual environment.
2. Install dependencies:
   pip install -r requirements.txt
3. Run:
   python main.py
